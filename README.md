# 📚 Книжный магазин "Читатель"

Интерактивный веб-сайт книжного магазина с более чем 300 реальными книгами и динамической системой акций.

## ✨ Возможности
- 📖 Более 320 настоящих книг с обложками
- 🏷️ Динамическая система акций и скидок
- 🔍 Поиск по названию, автору и категориям
- 🛒 Корзина с возможностью изменения количества
- ❤️ Избранное
- 👤 Регистрация и авторизация пользователей
- 📱 Адаптивный дизайн

## 🚀 Как запустить
Просто откройте файл `index.html` в любом браузере.
